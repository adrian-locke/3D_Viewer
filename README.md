# 3D Viewer

An interactive 3D model viewer built with WebGL.

## View Model

[**Open scene.json in viewer**](./viewer.html?model=scene.json)

Click the link above to open the 3D model in preview mode. Use the following controls:

- **Drag** to rotate
- **Right-drag** or **Shift+drag** to pan
- **Scroll** to zoom
- **Click** to select parts
- **Double-click** to isolate parts
- **F** - Fit view
- **W** - Toggle wireframe
- **G** - Toggle grid
- **A** - Toggle axes
- **S** - Save PNG
- **P** - Show/hide parts panel

## Features

- Interactive 3D visualization
- Part selection and isolation
- Adjustable lighting and rotation speed
- Wireframe mode
- Grid and axis display
- Dark mode support
- PNG export
